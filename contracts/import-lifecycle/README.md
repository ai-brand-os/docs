# Import polling projection 1.0.0

Date 2026-10-18. **Specified — Pending Product/Architecture Review (D-AUD-07)**. [ADR-012](../../domain/11_IMPORT_LIFECYCLE_ADR.md) is canonical for lifecycle/closure. [JSON Schema](1.0.0/status.schema.json) defines a safe application projection for the existing GET import-job polling route. It is not a new public endpoint, authoritative status table or approved generic API/error contract (D-AUD-08 remains open).

All fields are required; closureArtifactId is explicitly null until a verified durable closure exists, publicationRefs may be empty, unknown properties reject. importId equals correlationId, brandId is authenticated-scoped. status uses only SUBMITTED/VALIDATING/PROCESSING/EXTRACTING/READY_FOR_REVIEW/COMPLETED/FAILED/REJECTED_NO_CANDIDATES. reasonCode and nextAction explain recovery/partial/finalization without new visible states. pendingDecisionCount equals candidateSummary.pending; eligible equals accepted+editedAccepted+rejected+pending+invalidated. Counts exclude governance-ineligible/superseded attempts. Accepted includes CONFIRM only; editedAccepted separate, never double-counted. Empty pre-review counts do not imply nothing extracted.

terminal=true requires verified closureArtifactId and existing terminal status, retryAvailable=false. Terminal no-candidate/rejected/failure outcomes are distinguished by reasonCode and references. Nonterminal retry is allowed only under the same authorized control/operation budget; closing FAILED prevents same-correlation restart. Complete review without closure is READY_FOR_REVIEW/FINALIZING. Missing publication transaction evidence is PUBLICATION_RECONCILING. Legacy controls absent/unsupported is RECOVERY_REQUIRED with nextAction RECONCILE, never guessed terminal.

version is a 64-character SHA256 of stable-json-v1 over authorized semantic projection, ordered control/selected-Artifact/decision/publication IDs and visible lifecycle/lease/retry overlay. Serve quoted value as HTTP ETag. No timestamp-only order or latest-row query establishes version/completion. Response contents never include raw document/prompt text, provider trace, internal stack or secrets. Current Owner/tenant/deletion checks precede status/candidate reads, including conditional GET; unauthorized requests get non-disclosing 404, not 304 or cached content. Caches are tenant-scoped and rebuildable.

[Example completed projection](1.0.0/example.json) is synthetic and [lifecycle fixtures](../../validation/import_lifecycle.fixtures.json) supply source records. [Tests](../../validation/import_lifecycle.test.cjs) cover AT-18-01–24 and schema negatives. Run `ARTIFACT_VALIDATOR_PACKAGE_ROOT=../backend/node_modules/ajv-formats node validation/import_lifecycle.test.cjs` from repository root or use pinned validation dependencies with `npm --prefix validation run test:import`. [Results](../../validation/TASK18_RESULTS.md) distinguish offline contract models, PostgreSQL mechanism probes and untested application/queue behavior.

No new forced-close/cancel command or bulk-discard body is defined. Candidate PATCH retains existing expectedRevisionId and Idempotency-Key; exact public DTO/error/conditional mutation integration stays D-AUD-08/D-LEARN-02. Reader-before-writer rollout must preserve old public status vocabulary, authorize before revalidation and reject unknown projection versions. Historical Artifact v2.0 and Gateway1.0 bundles are unchanged; [proposed Artifact2.1 control](../artifacts/2.1.0/README.md) requires separate review before runtime adoption.
