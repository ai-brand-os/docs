# AI Brand OS Documentation

[MVP_SCOPE.md](MVP_SCOPE.md) is the canonical MVP scope and feature matrix. All Bibles, PRDs, discovery hypotheses, service specifications, domain documents and the planned Prisma schema conform to its boundaries. Documentation approval is not evidence that a feature is implemented.

[DECISION_REGISTER.md](DECISION_REGISTER.md) records approval evidence, pending Founder decisions and current PRD sign-off gates.

[DOCUMENTATION_CHANGELOG.md](DOCUMENTATION_CHANGELOG.md) records lifecycle reconciliation and fixed, open, or superseded notes.

[PRODUCT_METRICS.md](PRODUCT_METRICS.md) defines proposed onboarding goals, exact events, abandonment handling, weighted completeness and separate readiness.

[COMMERCIAL_PACKAGING.md](COMMERCIAL_PACKAGING.md) defines proposed Starter/Pro single-business offers, fixed brand/account limits and future Agency requirements.

[KNOWLEDGE_PROVENANCE.md](KNOWLEDGE_PROVENANCE.md) defines field evidence, approval/version history, conflict review, restoration, persisted completeness, APIs and migrations.

[DATA_LIFECYCLE.md](DATA_LIFECYCLE.md) defines conversation access denial, proposed retention, physical purge, backups, and approval decisions.

[Future export design](domain/06_FUTURE_EXPORT_DESIGN.md) records the Phase 2 proposal separately from the MVP schema.
